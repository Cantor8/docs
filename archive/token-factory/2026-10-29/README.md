# Token Factory archive — 29 October 2026

This directory preserves the four original Token Factory pages byte for byte from
Cantor8/docs commit 8db95a37e70cadd5b590447166ffe358e34fab8e.

The replacement pages come from Cantor8/token-factory PR #146, commit
a1aecc2d707a10f9196dec25d55156b6070bca4f. All 11 source documents were adapted
to Mintlify MDX with their code samples and technical content retained.

`archive/` is excluded by `.mintignore`. These files are available in GitHub,
and are not published as pages, navigation entries, or search results.
Their original links are preserved for historical accuracy, not rewritten.

Old public URLs are redirected to the current introduction, evaluation,
launch, and operations pages in `docs.json`.
