## Public API: `C8WalletProvider`

| Method | Parameters | Return Type |
| --- | --- | --- |
| `connect()` | None | `Promise<void>` |
| `disconnect()` | None | `Promise<void>` |
| `status()` | None | `Promise<{ connected: boolean; walletVersion?: string }>` |
| `getInstruments()` | None | `Promise<InstrumentListPayload>` |
| `getActiveContracts()` | `input?: GetActiveContractsInput` | `Promise<ActiveContractsPayload>` |
| `getLedgerUpdates()` | `input?: GetLedgerUpdatesInput` | `Promise<LedgerUpdatesPayload>` |
| `getAccounts()` | `instrumentId?: string` | `Promise<AccountListPayload>` |
| `send()` | `input: SendInput` | `Promise<SubmitTransferResultPayload>` |
| `createSwapOffer()` | `input: CreateSwapOfferInput` | `Promise<SubmitTransferResultPayload>` |
| `signMessage()` | `message: string, partyId?: string` | `Promise<string>` |
| `signAndExecute()` | `input: SignAndExecuteInput` | `Promise<void>` |
| `checkTxStatusById()` | `input: { txId: string }` | `Promise<TransferStatusResponsePayload>` |
| `on()` | `event: T, cb: Listener<C8EventByType<T>>` | `() => boolean` |

---

## Constructor

Creates a new wallet provider instance.

```ts
new C8WalletProvider(config)
```

<ParamField path="dappUrl" type="string">
  URL of the dApp initiating the connection. Defaults to the current page origin.
</ParamField>

<ParamField path="dappName" type="string" required>
  Name of the dApp. Must match the name registered with the wallet.
</ParamField>

<ParamField path="network" type="string">
  Canton network to connect to. Use `"devnet"`, `"testmainnet"`, or `"mainnet"`. Defaults to `"mainnet"`.
</ParamField>

---

## connect

Opens the C8 Wallet popup and establishes the `postMessage` channel. The user sees a connection approval screen in the wallet.

```ts
connect(): Promise<void>
```

<ResponseField name="returns" type="Promise<void>">
  Resolves when the user approves the connection.
</ResponseField>

<Note>
  Call interactive methods from a user gesture, such as a button click, to avoid `POPUP_BLOCKED` errors.
</Note>

---

## disconnect

Closes the wallet popup and tears down the `postMessage` channel. Emits the `disconnected` event.

```ts
disconnect(): Promise<void>
```

## status

```ts
status(): Promise<{ connected: boolean, walletVersion?: string }>
```

<ResponseField name="connected" type="boolean">

<ResponseField name="walletVersion" type="string">

## getActiveContracts

Returns active contracts visible to the connected account. You can filter the Scanner active contract set by template or interface.

```ts
getActiveContracts(input?: GetActiveContractsInput): Promise<ActiveContractsPayload>
```

<ParamField path="partyId" type="string">
  Account party ID. Defaults to the connected primary account. Direct provider requests can only use the primary account.
</ParamField>

<ParamField path="templateIds" type="string[]">
  Template IDs to include.
</ParamField>

<ParamField path="interfaceIds" type="string[]">
  Interface IDs to include.
</ParamField>

<ParamField path="activeAtOffset" type="string">
  Nonnegative signed 64-bit ledger offset for a point-in-time snapshot. Pass the offset as a decimal string.
</ParamField>

<ParamField path="includeCreatedEventBlob" type="boolean">
  Whether each contract should include its Base64-encoded created-event blob. Defaults to `false`.
</ParamField>

<ParamField path="limit" type="number">
  Maximum number of rows to return. Must be a positive 32-bit integer. Defaults to `10000`.
</ParamField>

<ParamField path="paginated" type="boolean">
  Whether Scanner should order rows by contract ID for pagination. Defaults to `true`.
</ParamField>

<ParamField path="after" type="string">
  Contract ID after which Scanner should return rows. Pass the previous contract ID unchanged.
</ParamField>

<ResponseField name="returns" type="Promise<ActiveContractsPayload>">
  An array of Scanner contract rows.
</ResponseField>

```ts
const contracts = await c8.getActiveContracts({
  templateIds: ["package-id:Module:Template"],
  includeCreatedEventBlob: true,
  limit: 10000,
});

console.log("Active contracts:", contracts);
```

## getLedgerUpdates

Returns one page of ledger updates visible to the connected account. Use the returned cursor to request the next page with the same filters.

```ts
getLedgerUpdates(input?: GetLedgerUpdatesInput): Promise<LedgerUpdatesPayload>
```

<ParamField path="partyId" type="string">
  Account party ID. Defaults to the connected primary account. Direct provider requests can only use the primary account.
</ParamField>

<ParamField path="templateIds" type="string[]">
  Template IDs to include.
</ParamField>

<ParamField path="cursor" type="string">
  Cursor returned as `nextCursor` by the previous request. Pass it unchanged.
</ParamField>

<ParamField path="eventType" type='"created" | "exercised"'>
  Event type to include.
</ParamField>

<ParamField path="consuming" type="boolean">
  Whether to include consuming or non-consuming exercise events.
</ParamField>

<ParamField path="limit" type="number">
  Maximum number of nodes to return. Must be from `1` through `1000`. Defaults to `500`.
</ParamField>

<ResponseField name="nodes" type="LedgerNode[]">
  Ledger nodes in this page.
</ResponseField>

<ResponseField name="nextCursor" type="string">
  Cursor for the next page, when more updates are available.
</ResponseField>

<ResponseField name="bounds" type="{ floorOffset: number; headOffset: number }">
  Scanner's retained offset range, when available.
</ResponseField>

<ResponseField name="gap" type="{ fromOffset: number; toOffset: number; reason?: string }">
  Lost history detected before or within the requested range, when present.
</ResponseField>

<ResponseField name="complete" type="boolean">
  Whether this page reached Scanner's current fetch frontier. New updates can arrive later.
</ResponseField>

```ts
const filters = {
  templateIds: ["package-id:Module:Template"],
  limit: 500,
};

const page = await c8.getLedgerUpdates(filters);
const nextPage = page.nextCursor
  ? await c8.getLedgerUpdates({ ...filters, cursor: page.nextCursor })
  : undefined;
```

<Note>
  An empty page can still return a new cursor. If `gap` is present, the result does not represent complete ledger history.
</Note>

## getAccounts

Returns accounts and their holdings. If `instrumentId` is provided, filters to accounts holding that instrument.

```ts
getAccounts(instrumentId?: string): Promise<AccountListPayload>

type AccountListPayload = {
  accounts: Array<{
    accountName?: string
    partyId: string
    publicKey: string
    validator: {
      id: string
      name: string
    }
    holdings: Array<{
      instrumentId: string
      balance: number
      balanceUsd: number
    }>
  }>
}
```

<ParamField path="instrumentId" type="string">
  Optional. Filters accounts to those holding this instrument.
</ParamField>

<ResponseField name="accountName" type="string">
  Optional display name for the account.
</ResponseField>

<ResponseField name="partyId" type="string">
  Canton party identifier for the account.
</ResponseField>

<ResponseField name="publicKey" type="string">
  Public key associated with the account.
</ResponseField>

<ResponseField name="validator" type="ValidatorInfo">
  Validator assigned to the account as `{ id: string, name: string }`.
</ResponseField>

## send

Submits a transfer on the Canton ledger. Opens an approval screen in the wallet popup.

```ts
send(input): Promise<SubmitTransferResultPayload>
```

<ParamField path="senderPartyId" type="string" required>
  Canton `partyId` of the sender.
</ParamField>

<ParamField path="instrumentId" type="string" required>
  Asset to transfer.
</ParamField>

<ParamField path="amount" type="number" required>
  Transfer amount.
</ParamField>

<ParamField path="receiverPartyId" type="string" required>
  Canton `partyId` of the recipient.
</ParamField>

<ParamField path="memo" type="string">
  Optional text memo attached to the transfer.
</ParamField>

<ParamField path="metadata" type="Record<string, string>">
  Optional arbitrary key-value metadata.
</ParamField>

<ResponseField name="txId" type="string">
  Transaction ID assigned by the Canton ledger. Use it with `checkTxStatusById`.
</ResponseField>

## createSwapOffer

Creates a multi-leg swap offer and opens the wallet approval UI. Amounts in swap legs are decimal strings.

```ts
createSwapOffer(input: {
  partyId: string;
  swap: MultiLegSwapSpecRequest;
  commandId?: string;
}): Promise<SubmitTransferResultPayload>
```

<ParamField path="partyId" type="string" required>
  Party creating the swap offer.
</ParamField>

<ParamField path="commandId" type="string">
  Optional idempotency key for the submission.
</ParamField>

<ParamField path="swap.swapId" type="string" required>
  Unique identifier for the swap.
</ParamField>

<ParamField path="swap.acceptorPartyId" type="string" required>
  Party allowed to accept the swap.
</ParamField>

<ParamField path="swap.creatorLegs" type="SwapLegRequest[]" required>
  Assets the creator provides. Each leg contains `receiver`, `instrument`, `amount`, `legId`, and an optional `reason`.
</ParamField>

<ParamField path="swap.acceptorLegs" type="SwapLegRequest[]" required>
  Assets the acceptor provides. Each leg uses the same shape as a creator leg.
</ParamField>

<ParamField path="swap.creatorTransferLegs" type="SwapTransferLegRequest[]" required>
  Additional transfer legs supplied by the creator. Pass an empty array when the swap has none.
</ParamField>

<ParamField path="swap.settleBefore" type="string" required>
  ISO 8601 timestamp after which the swap can no longer settle.
</ParamField>

<ParamField path="swap.meta" type="Record<string, string>" required>
  Application metadata for the swap. Pass an empty object when you have no metadata.
</ParamField>

<ResponseField name="txId" type="string">
  Transaction ID assigned after the wallet submits the swap offer.
</ResponseField>

See [Multi-leg swap offers](/wallet-sdk/transfer-types#multi-leg-swap-offers) for a complete example.

## signMessage

Asks the wallet to sign an arbitrary string. You can bind the request to a specific account by passing its party ID.

```ts
signMessage(message: string, partyId?: string): Promise<string>
```

<ParamField path="message" type="string" required>
  Message to show in the wallet approval UI and sign.
</ParamField>

<ParamField path="partyId" type="string">
  Optional party whose account should sign the message.
</ParamField>

<ResponseField name="returns" type="Promise<string>">
  Signature string returned by the wallet.
</ResponseField>

---

## signAndExecute

Signs and executes custom DAML commands via the connected wallet. Use this for templates, choices, and contract workflows beyond the SDK's high-level methods. See [Transactions and signing](/wallet-sdk/transfer-types#sign-and-execute-custom-daml-commands) for the full example.

```ts
signAndExecute(input): Promise<void>
```

<ParamField path="note" type="string" required>
  Human-readable note shown to the user in the wallet UI.
</ParamField>

<ParamField path="partyId" type="string" required>
  The party submitting the command.
</ParamField>

<ParamField path="commandId" type="string" required>
  Unique idempotency key for this submission (e.g. a UUID).
</ParamField>

<ParamField path="commandsJson" type="string" required>
  JSON-serialized array of DAML commands (`CreateCommand`, `ExerciseCommand`, etc.).
</ParamField>

<ParamField path="disclosedContracts" type="string" required>
  JSON-serialized array of contracts disclosed to the participant to authorize the command.
</ParamField>

---

## on

Subscribes to a wallet event. Returns an unsubscribe function. See [Events](/wallet-sdk/events) for the full event reference.

```ts
on<T extends C8EventType>(event: T, cb: Listener<C8EventByType<T>>): () => boolean
```

<ParamField path="event" type="string" required>
  Event type to subscribe to (e.g. `"connected"`, `"txChanged"`).
</ParamField>

<ParamField path="cb" type="Listener" required>
  Callback invoked with the typed event payload.
</ParamField>

<ResponseField name="returns" type="() => boolean">
  Unsubscribe function. Call it to remove the listener.
</ResponseField>

---

## checkTxStatusById

Polls the Canton ledger for the current status of a previously submitted transaction.

```ts
checkTxStatusById(input): Promise<TransferStatusResponsePayload>
```

<ParamField path="txId" type="string" required>
  Transaction ID returned by `send()`.
</ParamField>

<ResponseField name="returns" type="Promise<TransferStatusResponsePayload>">
  Current ledger status for the given transaction.
</ResponseField>
