---
title: "Installation"
description: "Install the C8 Wallet SDK in a browser-based dApp."
---

Install C8 Wallet SDK from npm:

<CodeGroup>

```bash npm
npm install @cantor8/wallet-connect-sdk
```

```bash yarn
yarn add @cantor8/wallet-connect-sdk
```

```bash pnpm
pnpm add @cantor8/wallet-connect-sdk
```

</CodeGroup>

## Requirements

- Modern browser with `window.postMessage` support
- A dApp served over HTTPS (or `localhost` for development)
